# Серуен — ИИ-помощник по прогулкам в Астане

RAG-система: автоматически собранная база POI Астаны + LLM (Gemini) → 1–3 конкретные рекомендации рядом с пользователем с объяснением «почему», временем визита, честной пометкой уверенности и источника, плюс мини-маршрут.

Задание хакатона: [docs/TASK.md](docs/TASK.md).

## Структура и владельцы

| Папка | Владелец | Что внутри |
|---|---|---|
| `contracts/` | Координатор | `poi.schema.json`, `api.md` — общий контракт. Менять только через координатора |
| `pipeline/`, `data/` | Агент 1 (данные) | Автоматический сбор: OSM Overpass, Wikidata, 2GIS (если есть ключ) → `data/pois.json` |
| `backend/` | Агент 2 (RAG) | FastAPI: разбор запроса → фильтры → поиск → ранжирование → генерация → валидатор → маршрут |
| `frontend/` | Агент 3 (UI) | Vite + React + TS + Leaflet: карта + чат, пресеты, ползунок времени |
| `docs/`, `eval/` | Агент 4 (доки и проверка) | Концепция, тестовые сценарии, этика/privacy, слайды, сценарий видео, авто-оценка |

Каждый агент меняет **только свои папки** и ничего не коммитит — коммитит координатор.

## Запуск (будет дополнено)
```bash
cp .env.example .env
```
