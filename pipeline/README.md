# Пайплайн данных Seruen

Одна команда собирает с нуля базу POI Астаны по `contracts/poi.schema.json`:

- `data/pois.json` — полная база (OSM + Wikidata/Википедия + 2GIS), **не публикуется** (условия 2GIS);
- `data/pois_open.json` — открытая выгрузка только из OSM и Wikidata/Википедии (её можно класть в репозиторий);
- `data/stats.md` — отчёт с колонками «полная / открытая» и проверками покрытия;
- `data/LICENSE_DATA.md` — лицензии и атрибуция.

```bash
python3 -m venv pipeline/.venv && pipeline/.venv/bin/pip install -r pipeline/requirements.txt  # один раз
pipeline/.venv/bin/python pipeline/run_all.py            # из кэша data/raw/, если он есть
pipeline/.venv/bin/python pipeline/run_all.py --refresh  # перекачать OSM/Wikidata/Википедию
```

Без зависимостей тоже работает (`python3 pipeline/run_all.py`): тогда OSM берётся только через Overpass,
а схема проверяется встроенным валидатором.

Флаги: `--skip-images`, `--osm auto|overpass|geofabrik` (auto — выгрузка Geofabrik, если она скачана и есть pyosmium, иначе Overpass с откатом на Geofabrik), `--skip-wikidata`, `--skip-2gis`, `--refresh-2gis` (ответы 2GIS по умолчанию берутся из кэша даже при `--refresh`, чтобы не тратить лимит ключа). Зависимостей нет — только стандартная библиотека Python 3.10+.
Если установлен `jsonschema`, валидация идёт через него, иначе — встроенная проверка схемы.

## Шаги

| # | Шаг | Модуль |
|---|---|---|
| 1 | OSM: Overpass (5 лёгких запросов по bbox Астаны, `out center`) или выгрузка Geofabrik `kazakhstan-latest.osm.pbf` (~225 МБ, разбор pyosmium ~1 мин). Отбор объектов описан один раз в `SELECTORS`: еда, культура, парки, wellness (бассейны, фитнес, сауны, спа), магазины и аптеки, достопримечательности | `sources/osm.py` |
| 2 | Нормализация: теги → `category`, `tags`, эвристики `indoor`/`kid_friendly`/`typical_visit_min`, проверка `opening_hours`, шаблонные описания | `normalize.py`, `opening_hours.py` |
| 3 | Дедупликация: одинаковое нормализованное имя и < 80 м → один объект, `sources` объединяются | `normalize.dedupe` |
| 4 | Wikidata SPARQL (P131* = Q1520): русские названия, описания, sitelinks → `popularity`, категория по P31, новые объекты, которых нет в OSM. Для статей ruwiki — 1–3 предложения из summary Википедии | `sources/wikidata.py` |
| 5 | Резерв из `data/seed/` — только места, которых не нашли автоматические источники (например, «Нур Алем») | `sources/seed.py` |
| 6 | 2GIS Places API — **только если в `.env` есть `TWOGIS_API_KEY`**: добор по рубрикам (бассейны, фитнес, спа, сауны, боулинг, квесты, караоке, катки, батуты, детские центры, кино, музеи, галереи, театры, смотровые, парки, коворкинги, кофейни, супермаркеты, продукты 24 ч, одежда, обувь, канцтовары, книжные, аптеки) в радиусе 3 км от Байтерека, Mega Silk Way и старого центра; место берётся, только если рубрика 2GIS подтверждает тип. Затем часы работы, рейтинг и контакты для уже найденных мест. Без ключа тихо пропускается | `sources/twogis.py` |
| 5b | Достопримечательность или учреждение (`sights.py`): министерства, суды, архивы, парламент, посольства, ЖК, офисные башни (по тегам OSM office/government/building, классам P31 Wikidata и названию) → `other` + тег `institution`; вокзалы и аэропорт → `other` + `transport`. Главные туристические места из белого списка → тег `must_see` и буст popularity | `sights.py` |
| 6a | Фото: Wikidata P18 (или первый файл Commons-категории P373), OSM `wikimedia_commons`/`image` на Commons, главное изображение статьи Википедии (ru/kk/en, `prop=pageimages`) → метаданные Commons API пакетами по 50: ссылка, миниатюра, автор, лицензия. Только CC0 / PD / CC BY / CC BY-SA, файлы не скачиваются. Плюс `data/category_photos.json`: 3–6 нейтральных иллюстраций на категорию (`generic: true`, отобраны вручную, без узнаваемых вывесок; у wellness подтег `tag`: pool/fitness/sauna) и 5 обложек `hero` | `sources/images.py` |
| 7 | Второй проход дедупликации, `popularity` и `data_quality`, валидация по схеме, атомарная запись | `run_all.py`, `validate.py` |
| 8 | Открытая выгрузка: места только из 2GIS выбрасываются, у остальных поля из 2GIS откатываются к значениям OSM/Wikidata (снимок до 2GIS), источник `2gis` удаляется | `normalize.open_version` |
| 9 | Отчёт `data/stats.md`: категории, полнота полей, источники, покрытие 1 км вокруг Mega Silk Way / ЭКСПО / Байтерека, известные места | `stats.py` |

Сырые ответы кэшируются в `data/raw/` (в git не попадают): повторный запуск не обращается к API.

## Правила нормализации (кратко)

- **Имя**: русское название из ручной сид-базы для ключевых мест («Монумент «Байтерек»») → `name:ru` → ru-метка Wikidata → `name` (в OSM Астаны `name` чаще на казахском). Все варианты — в `name_i18n`.
- **Описание**: Википедия (summary) → описание Wikidata → OSM `description` → шаблон из полей («Кафе «X» по адресу …; есть Wi-Fi»). Шаблон помечается `description_source: "template"`, новых фактов не добавляет.
- **Часы работы**: исходная строка OSM / расписание 2GIS, переведённое в OSM-формат. Невалидные строки → `null` и список в отчёте. `opening_hours_source` и `opening_hours_checked_at` заполняются всегда, когда часы есть.
- **Теги**: `internet_access=wlan` → `wifi`, `socket*` → `sockets`, `outdoor_seating`, `wheelchair`, `vegan/vegetarian/halal`, поздние часы → `night`; по категории — `kids`, `indoor`, `quiet`, `view`, `photo`, `free`, `sight` и т. п.
- **Категории схемы для повседневных нужд**: `wellness` (бассейн/спа/сауна/фитнес — всегда с подтегом `swimming`/`pool`, `spa`, `sauna`, `fitness`/`gym`), `supermarket`, `convenience`, `clothes`, `shop`, `pharmacy`. Теги магазинов: `brand:<имя>` из OSM `brand`, `24_7` по часам работы, `stationery`, `books`, `shoes`, `kids_clothes`, `electronics`.
- **Тег `budget`** ставится только сетям из короткого списка `BUDGET_BRANDS` в `normalize.py` (позиционируют себя как магазины низких цен); при сомнении сеть туда не добавляется.
- **Безымянные детские площадки** (OSM way без имени) включены как «Детская площадка» с низкой `popularity` — для сценария «с ребёнком». Площадки детсадов/школ и `access=private` отброшены.
- **popularity** (0–1): наличие в Wikidata, статья в Википедии, число sitelinks, число отзывов 2GIS.
- **data_quality** (0–1): часы работы, реальное описание, рейтинг, контакты, адрес, известная доступность, свежесть.

## Лицензии и атрибуция

- **OpenStreetMap** — ODbL 1.0. Атрибуция обязательна: «© участники OpenStreetMap», https://www.openstreetmap.org/copyright. Производная база `data/pois.json` подпадает под ODbL (share-alike).
- **Wikidata** — CC0.
- **Википедия** (тексты описаний) — CC BY-SA 4.0; ссылка на статью сохраняется в `sources`.
- **2GIS Places API** — по условиям использования API 2GIS (https://dev.2gis.com/). Перед публикацией базы с данными 2GIS проверить, разрешает ли тариф ключа хранение ответов; при сомнении собирать с `--skip-2gis`.

## Обновление по расписанию

Часы работы и заведения меняются, поэтому базу стоит пересобирать раз в неделю (cron, из корня репозитория):

```cron
0 4 * * 1  cd /path/to/seruen && python3 pipeline/run_all.py --refresh >> data/pipeline.log 2>&1
```

Бэкенд перечитывает `data/pois.json` при изменении файла; запись атомарная (tmp → rename).

## Ограничения данных

- OSM в Астане неполон: часы работы есть примерно у трети мест, рейтингов в OSM нет совсем (только из 2GIS).
- Временные события, сезонные закрытия, ремонты не отражены — бэкенд должен говорить о неуверенности, если часы неизвестны или проверены давно.
- Координаты площадных объектов (парки, ТЦ) — центр полигона, вход может быть в стороне.
- Эвристики (`indoor`, `kid_friendly`, `typical_visit_min`) — оценки по категории, не факты.
- Лимит демо-ключа 2GIS: модуль тратит не больше `TWOGIS_MAX_REQUESTS` (по умолчанию 250) запросов за прогон.
