# Запросы на изменение контрактов

Формат: `- [агент N] что изменить — зачем`. Координатор разбирает и отвечает здесь же.

- [агент 4] Добавить в запрос `/api/recommend` необязательное поле `weather_override: {"temp_c": -20, "wind_ms": 9}` (только для демо/eval; в UI — переключатель «зима −20»). Зачем: погода берётся из Open-Meteo вживую, и сценарий «вечер зимой −20» (фишка Астаны) нельзя воспроизвести осенью ни в демо, ни в eval. До решения eval шлёт поле только с флагом `--weather-override`.
- [агент 3] В элементе `/api/presets` разрешить необязательные поля `mode` (`walk|car|transit`) и `icon` (эмодзи). Зачем: пресет «аэропорт» логично запускать на машине, а иконки кнопок сейчас угадываются по id. Фронт уже читает оба поля, если их нет — работает эвристика (airport → car).

**Решение координатора (2026-10-20):** оба запроса приняты и внесены в `contracts/api.md`: `weather_override` в запросе `/api/recommend` (и в пресетах), `mode` + `icon` в пресетах.

- [координатор] Добавлены категории supermarket, convenience, clothes, shop, pharmacy, wellness и теги для магазинов (24_7, budget, brand:*, stationery…) — пользователь хочет искать магазины 24/7, Magnum, недорогую одежду, канцтовары; бассейны/спа/фитнес → wellness.

- [координатор] Добавлено поле `image` (Wikimedia Commons, с автором и лицензией) в POI и в рекомендации API — для фото в карточках по запросу пользователя.
