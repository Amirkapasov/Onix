# Серуен — интерфейс демо (frontend)

Vite + React 19 + TypeScript + Tailwind 4 + react-leaflet (тайлы OpenStreetMap с атрибуцией).

## Запуск

```bash
cd frontend
npm install
npm run dev            # http://localhost:5173, прокси /api → http://localhost:8000
```

Режим данных задаётся в `frontend/.env.local` (перезапустите `npm run dev` после изменения):

| `VITE_USE_MOCK` | Что происходит |
|---|---|
| `0` (по умолчанию) | Реальный бэкенд через прокси `/api` |
| `1` | Моки из `src/mocks/*.json` (бэкенд не нужен) — 4 сценария по `contracts/api.md` |

Сборка: `npm run build` (typecheck + бандл в `dist/`).

## Что на экране
- **Карта** (слева; на мобиле сверху): точка пользователя с кругом ~100 м, нумерованные маркеры 1–3, линия маршрута (`route.geometry`, иначе — прямые между остановками), клик по карте = новая локация, серые точки POI из `/api/pois`.
- **Панель**: запрос (Enter — отправить), история запросов в сессии, кнопки пресетов из `/api/presets` (клик = локация + время + фильтры + запрос и сразу отправка), ползунок времени (сейчас / утро / день / вечер / ночь 23:30), фильтры 🧒 ♿ 👥 🏠, пешком/на машине, язык RU/ҚАЗ/EN (смена языка перезапрашивает ответ).
- **Карточки**: название, категория, расстояние/время в пути, время на визит, «Почему», «Что делать», бейдж статуса работы по уверенности (зелёный / жёлтый / серый / красный) и бейдж источника «📍 Из базы · OSM/Wikidata» со ссылкой. Наведение на карточку подсвечивает маркер, клик по маркеру прокручивает к карточке.
- **«💡 Идея ИИ»** — отдельный блок для `ideas` с пометкой «не проверено по базе».
- **Мини-маршрут**: «N места · X мин · Y км» и шаги.
- **«Что учтено»**: краткие чипы над карточками + полный раскрывающийся блок из `context_used` / `parsed_intent` / `llm` с примечанием о приватности.
- `warnings` — жёлтая плашка; режим деградации (`llm.provider = "none"`) — тёмная плашка «Режим без ИИ».
- Состояния: скелетоны при загрузке, ошибка с кнопкой «Повторить», пустое состояние с подсказкой.

## Приватность
- Координаты огрубляются до 3 знаков (~100 м) **до** отправки (`src/geo.ts → coarsen`, дополнительно в `api.ts`).
- Геолокация браузера — только по кнопке «Моя геолокация» после понятного текста согласия; по умолчанию — пресет или клик по карте.
- В `localStorage` хранится только язык.

## Для демо и видео
- Deep-link: `http://localhost:5173/?preset=<id>&lang=kk` — сразу запускает сценарий (id из `/api/presets`).
- `?static=1` — без анимаций карты (для скриншотов).
- Скриншоты для слайдов: `bash scripts/screenshots.sh [preset1] [preset2] [preset3] [preset4]` → `screenshots/*.png` (нужен Google Chrome и запущенный `npm run dev`).
  Текущие скриншоты сняты на моках. Для живого бэкенда: `bash scripts/screenshots.sh megasilkway_walk night_unusual kids airport_2h`.

## Структура
```
src/
  App.tsx                 состояние, запрос, панель
  api.ts                  клиент API + моки (VITE_USE_MOCK)
  geo.ts                  огрубление, время Астаны (UTC+5), форматирование
  i18n.ts                 RU / ҚАЗ / EN
  types.ts                типы по contracts/api.md
  components/             MapView, Controls, Results, RecommendationCard, ContextUsed
  mocks/                  presets.json, recommend.json
```
