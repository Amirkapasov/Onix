# Seruen — интерфейс демо (frontend)

Vite + React 19 + TypeScript + Tailwind 4 + react-leaflet (тайлы OpenStreetMap с атрибуцией).

## Запуск

```bash
cd frontend
npm install
npm run dev            # http://localhost:5173, прокси /api → http://localhost:8000
```

Режим данных задаётся в `frontend/.env.local` (перезапустите `npm run dev` после изменения):

| `VITE_USE_MOCK` | Что происходит |
|---|---|
| `0` (по умолчанию) | Реальный бэкенд через прокси `/api` |
| `1` | Моки из `src/mocks/*.json` (бэкенд не нужен) — 4 сценария по `contracts/api.md` |

Сборка: `npm run build` (typecheck + бандл в `dist/`).

## Дизайн
- Шрифты: **Unbounded** (заголовки) и **Onest** (текст), Google Fonts; казахские ә ғ қ ң ө ұ ү һ і покрываются подмножеством cyrillic-ext (проверено в браузере).
- Палитра Астаны: глубокий синий `ink-900 #0B2545` для текста, бирюза `#00AFCA` и золото `#FEC50C` как акценты, много белого. Орнамент «қошқар мүйіз» — один раз, в шапке (`components/Ornament.tsx`).
- Иконки — линейные `lucide-react`; эмодзи из API (`preset.icon`) не показываются.
- Десктоп: панель слева, карта справа. Мобильный: карта сверху, выдача — лист снизу, наезжающий на карту.
- Карта: тайлы OSM с приглушающим фильтром (без ключа). CARTO теперь требует API-ключ; свой провайдер — `VITE_TILE_URL` и `VITE_TILE_ATTR` в `.env.local`.

## Фото
- Обложка — `hero` из `GET /api/category-photos`; запасной набор ссылок — `src/photos.ts`.
- Карточка: `recommendation.image` → фото категории с подписью «Иллюстрация» (без повторов в выдаче; фото другого конкретного места с чужим `poi_id` не используется, снятые в Астане — первыми) → цветовой блок с линейной иконкой.
- Под каждым фото — «Фото: автор · лицензия» со ссылками на страницу файла и лицензию. Это требование лицензий — не убирать. Файлы не хранятся в репозитории; см. `public/CREDITS.md`.

## Что на экране
- **Пустое состояние**: обложка с фото, поле запроса, строка «что отправится» (режим, время, фильтры), «Параметры» (время суток, пешком/на машине, с ребёнком, доступность, только в помещении, зима −20°, группа), список сценариев из `/api/presets`.
- **Выдача**: «Запрос: …», заголовок, контекст (локация ≈, время, погода), предупреждения, карточки (фото → название → «почему» → «что делать» → расстояние/время/рейтинг → статус работы точкой и текстом с уверенностью → источник), маршрут-таймлайн, «Идея от ИИ», «Что учтено». 0–1 мест — честный блок «ничего подходящего» с «Искать дальше» и «На машине».
- Наведение на карточку подсвечивает маркер, клик по маркеру прокручивает к карточке; клик по карте — новая точка.

## Приватность
- Координаты огрубляются до 3 знаков (~100 м) **до** отправки (`src/geo.ts → coarsen`, дополнительно в `api.ts`).
- Геолокация браузера — только по кнопке «Моя геолокация» после понятного текста согласия; по умолчанию — пресет или клик по карте.
- В `localStorage` хранится только язык.

## Для демо и видео
- Deep-link: `http://localhost:5173/?preset=<id>&lang=kk` — сразу запускает сценарий (id из `/api/presets`).
- `?static=1` — без анимаций (для скриншотов).
- `SERUEN_API=http://localhost:8001 npm run dev` — проксировать `/api` на другой бэкенд.
- Скриншоты для слайдов: `bash scripts/screenshots.sh` (живой бэкенд) или `bash scripts/screenshots.sh mock` → `screenshots/*.png` (нужен Google Chrome и запущенный `npm run dev`). Текущие сняты на живом бэкенде; если включить LLM, их стоит переснять — уйдёт плашка «Без ИИ».
- **❄️ Зима −20°** — переключатель симуляции погоды: отправляет `weather_override: {"temp_c": -20, "wind_ms": 9}`. Пресет с `weather_override` (например, «Зимний вечер») включает его сам; в «Что учтено» погода помечена «(симуляция)».
- Пресеты могут нести `mode` и `icon` — фронт их использует.

## Структура

```
  App.tsx                 состояние, запрос, панель
  api.ts                  клиент API + моки (VITE_USE_MOCK)
  geo.ts                  огрубление, время Астаны (UTC+5), форматирование
  i18n.ts                 RU / ҚАЗ / EN
  types.ts                типы по contracts/api.md
  components/             MapView, Controls, Results, RecommendationCard, ContextUsed
  mocks/                  presets.json, recommend.json
```
