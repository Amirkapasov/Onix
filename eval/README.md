# eval — авто-оценка Seruen

Только стандартная библиотека Python 3.10+. Запуск из корня репо.

```bash
python3 eval/run_eval.py                  # живой бэкенд http://localhost:8000 (сначала проверяет /api/health)
python3 eval/run_eval.py --mock good      # проверка самого скрипта без бэкенда
python3 eval/run_eval.py --mock bad       # мок с нарушениями — проверки должны их поймать
python3 eval/run_eval.py --only T07,T13   # отдельные кейсы
python3 eval/build_scenarios_doc.py       # пересобрать docs/TEST_SCENARIOS.md из cases.json
```

- Между кейсами пауза `--delay` (по умолчанию 13 с: free tier Gemini ~5 запросов/мин на модель, 38 кейсов ≈ 9–10 мин); 4–5 с — если допустимы ответы запасных моделей. Не запускать одновременно с демо и проверками бэкенда. Бэкенд кэширует ответы 30 мин — для честной задержки первый прогон после перезапуска.
- `cases.json` — 38 кейсов (тело запроса по `contracts/api.md` + ожидания). `expected_match` (категории / теги / regex по названию и описанию / indoor) — жёсткая проверка релевантности: каждое место должно соответствовать запросу; если подходящее открытое место в радиусе есть в базе — пустой ответ не засчитывается (`recall_if_available`). `require_open_confirmed` — открыто подтверждённо (24_7 или часы); `forbid_categories` — запрещённые категории (прогулка без магазинов).
- `report.md` — итоговые проценты (для слайда «Качество»), проверки, таблица по кейсам.
- `results/<id>.json` — сырые ответы для ручного разбора.
- База для проверки `poi_id` — `data/pois.json`, иначе `data/seed/pois_seed.json` (`--pois` для другой).
- `weather_override` из кейса (T07, зима −20) шлётся по умолчанию (поле есть в `contracts/api.md`); `--no-weather-override` — живая погода.

Жёсткие проверки (✗) — правила контракта; мягкие (△) — релевантность категории, разнообразие, маршрут в бюджете, «открыто на всё время визита», задержка ≤ 5 с.
- `report_notes.md` — ручные примечания к прогону; автоматически добавляются в конец `report.md` (кроме мок-режима). `--rescore` — пересчитать сохранённые ответы без запросов к API.
