# Тестовые сценарии «Серуен»

38 кейсов: 6 из задания хакатона + контекст (погода, ночь, группа, машина), доступность, языки (ru/kk/en), недостоверные данные (закрыто, ничего рядом, музей в понедельник), безопасность (опасный запрос, prompt injection), запрос вне Астаны, релевантность конкретных активностей (бассейн, фитнес, сауна, боулинг, каток, кино, серфинг) и магазины (24/7, Magnum, одежда, канцтовары, аптека ночью, прогулка без магазинов). Машиночитаемая версия — `eval/cases.json`, автопроверка — `python3 eval/run_eval.py`, результаты — `eval/report.md`.

> Документ собирается из `eval/cases.json` скриптом `eval/build_scenarios_doc.py` — правьте кейсы там.

## Общие правила (проверяются в каждом кейсе автоматически)

| # | Правило | Как проверяем |
|---|---|---|
| 1 | 1–3 рекомендации (0 допустимо только в помеченных кейсах — тогда обязателен warning) | `count`, `empty_has_warning` |
| 2 | Каждое место есть в базе POI — никаких выдуманных мест | `poi_in_db`: `poi_id` ∈ `data/pois.json` |
| 3 | Рекомендации — `source_type: poi_data`, придуманное LLM — только в `ideas` с `generated_idea` | `source_type` |
| 4 | Не рекомендуем закрытое на момент прихода (`client_time` + дорога) | `not_closed`: свой парсер OSM `opening_hours` |
| 5 | Нет «открыто сейчас», если часов нет (`state=unknown`) | `no_open_when_unknown` |
| 6 | `open_status` из допустимых значений, без `high` при отсутствии часов | `open_status_enum` |
| 7 | Расстояние посчитано кодом и правдоподобно (не меньше прямой, не больше 2× прямой) | `distance_consistent` (haversine) |
| 8 | Место в пределах бюджета расстояния кейса | `distance_budget` |
| 9 | `why` ≤ 200, `what_to_do` ≤ 250 символов, не пустые | `text_len` |
| 10 | Язык ответа = `lang` (ru / kk / en) | `lang`: доля кириллицы/латиницы, казахские буквы |
| 11 | Задержка ≤ 5 с (мягко), `context_used.data_note` есть (мягко) | `latency`, `context_used` |
| 12 | **Релевантность** (для конкретных запросов): каждое место соответствует запросу — категория, тег или слово в названии/описании (`expected_match`) | `relevance` — жёсткая |
| 13 | Если подходящее открытое место в радиусе в базе есть — пустой ответ не засчитывается; если нет — 0 рекомендаций + warning | `recall_if_available` |
| 14 | Для «круглосуточно / ночью» — каждое место открыто подтверждённо (тег 24_7 или часы); для прогулки — без магазинов | `open_confirmed`, `forbidden_category` |

Мягкие проверки (△) не валят кейс, но идут в отчёт: релевантная категория, разнообразие, маршрут в бюджете, место открыто на всё время визита.

*Базовый сценарий из задания: бюджет времени → радиус, прогулочные места*

| Вход | |

| Время | вт 20.10.2026 17:00 |
| Язык / режим | ru / пешком / маршрут |
| Фильтры | — |

**Ожидаемый ответ:** 1–3 прогулочных места (парк, бульвар, видовая точка, ЭКСПО) в пределах ~1,5 км; время визита укладывается в 30–60 мин; мини-маршрут

**Критерии прохождения:**
- Запрещены категории (авто): supermarket, convenience, clothes, shop, pharmacy
- Релевантность (авто): каждое место — категории park, viewpoint, landmark, monument; или теги walk; или слова `парк|бульвар|набережн|аллея|сквер|park|boulevard|Нур Алем|Nur Alem|ЭКСПО|EXPO`

| Вход | |
|---|---|
| Запрос | «Хочу просто погулять часик, подышать воздухом.» |
| Локация | Бульвар Нуржол (51.127, 71.433) |
| Время | вт 20.10.2026 18:00 |
| Язык / режим | ru / пешком |
| Фильтры | — |

**Ожидаемый ответ:** Парки, бульвары, набережные, видовые точки — ни одного магазина

**Критерии прохождения:**
- Запрещены категории (авто): supermarket, convenience, clothes, shop, pharmacy
- Релевантность (авто): каждое место — категории park, viewpoint, landmark, monument; или теги walk; или слова `парк|бульвар|набережн|аллея|сквер|park|boulevard`
- Нет категорий supermarket / convenience / clothes / shop / pharmacy
- Места прогулочные
