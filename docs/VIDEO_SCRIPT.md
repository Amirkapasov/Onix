## Подготовка к записи
- Прогреть бэкенд (по одному запросу на каждый пресет), чтобы не было пауз.
- Закрыть лишние вкладки, масштаб браузера 110–125 %, курсор крупный.
- Запись: OBS / QuickTime, звук отдельно (тихая комната), затем наложить.
- Не показывать `.env`, ключи, консоль с логами.
- В описании видео: ссылка на репозиторий, атрибуция «© участники OpenStreetMap», Wikidata, 2GIS API, Open-Meteo.
