# Этика и приватность «Серуена»

## 1. Локация — минимум данных
- **Огрубление на клиенте**: координаты округляются до 3 знаков (~100 м) ещё в браузере, до отправки на сервер. Точная точка сервер не покидает браузер.
- **Не храним**: нет аккаунтов, нет истории запросов, нет базы пользователей. Координаты не пишутся в логи (в техлогах — максимум 2 знака, ~1 км, без привязки к человеку).
- **Погода — по центру города**, а не по координатам пользователя: сторонний сервис (Open-Meteo) не узнаёт, где человек.
- **В LLM уходит не точка, а контекст**: «район Mega Silk Way», расстояния до кандидатов и их факты. Провайдер LLM получает только текст запроса.
- **Без геолокации тоже работает**: можно выбрать точку на карте или ориентир («я у Байтерека»).
- В каждом ответе — строка `data_note`: «Используются: огрублённая локация, время, фильтры. Координаты не сохраняются».

## 2. Прозрачность: что учтено и откуда факт
- Блок **«Что учтено»**: район, время, погода, режим (пешком/машина), фильтры, радиус поиска.
- У каждого места — **источник** (OSM / Wikidata / 2GIS) со ссылкой и датой проверки.
- **Факт и идея разделены**: рекомендации — только из базы (`poi_data`); всё, что LLM предложил сам, помечено «идея ИИ» (`generated_idea`) и показывается отдельно.
- Объяснение «почему» ссылается на конкретный факт: расстояние, часы, тег, погода.

## 3. Недостоверные и устаревшие данные
| Ситуация | Что делаем |
|---|---|
| Нет часов работы | `state=unknown`, уверенность low, «Часы неизвестны — уточните перед выходом»; никогда не пишем «открыто сейчас» |
| Часы из OSM | «Вероятно открыто» (medium) + дата проверки |
| Место закрыто на момент визита | Не рекомендуем; если пользователь просил именно его — warning и замена |
| Место может быть закрыто навсегда / переехало | Свежесть данных снижает `data_quality` и вес в ранжировании; источник с датой виден пользователю |
| Временные события (ярмарки, ремонт, концерты) | В MVP не используем как факт; при подключении афиш — только с датой и источником |
| Рядом ничего подходящего | Честно говорим и показываем ближайшее с реальным расстоянием, а не придумываем |
| LLM пытается добавить место вне базы (галлюцинация, prompt injection) | Валидатор удаляет любой `poi_id` вне кандидатов; проверяется в eval (кейс T18) |

## 4. Безопасность
- **Ночью** — только освещённые людные места и заведения, открытые по часам; пешие маршруты короче, предпочтение такси.
- **Не советуем опасное**: выход на лёд Есиля, крыши, стройки, закрытые территории, пустыри. На такие запросы — предупреждение и безопасная альтернатива (кейс T16).
- **Мороз и жара**: при < −10 °C и сильном ветре — короткие переходы и тёплые места; предупреждение об обморожении.
- **Экстренная помощь**: в интерфейсе и в предупреждениях — единый номер **112**.
- **Доступность**: при фильтре «кресло» показываем только места с подтверждённым `wheelchair=yes/limited`; «limited» помечаем; при нехватке данных — честное предупреждение.

## 5. Реклама и нейтральность
- Ранжирование — открытая формула (релевантность, расстояние, рейтинг, часы, погода). Платить за место в выдаче нельзя.
- Партнёрские промо (если появятся) — отдельный блок с явной пометкой «Партнёр», не смешиваются с рекомендациями и не влияют на `score`.

## 6. Лицензии данных
- **OpenStreetMap** — ODbL: атрибуция «© участники OpenStreetMap» в интерфейсе и документации; производная база открыта на тех же условиях.
- **Wikidata** — CC0.
- **2GIS** — только через официальный Places API по ключу и в рамках его условий; данные 2GIS не публикуем как открытый датасет.
- **Open-Meteo** — CC BY 4.0, атрибуция.
- Не скрейпим сайты, запрещающие это (2GIS web, Google Maps, Яндекс).

## 7. Ограничения ИИ
- LLM может ошибиться в тоне или переоценить место — поэтому факты и цифры считает код, а пользователь видит источник и уверенность.
- Ответ — рекомендация, а не гарантия: часы и доступность стоит уточнить перед выходом (об этом говорит интерфейс).
