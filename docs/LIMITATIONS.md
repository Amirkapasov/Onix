# Ограничения, риски и план развития

## Ограничения и риски

| Ограничение / риск | Влияние | Как смягчаем |
|---|---|---|
| Неполнота OSM: часы работы есть лишь у [TBD]% мест, описания — у [TBD]% | Часть мест с `unknown` | 2GIS API для часов и рейтингов; честная пометка уверенности; меньший вес в ранжировании |
| Устаревание: места закрываются, меняют часы | Рекомендация закрытого места | Пересбор по расписанию (cron), дата проверки у каждого места, `data_quality` учитывает свежесть |
| Временные события и ремонты не в базе | Неожиданно закрыто | Пометка «уточните перед выходом»; в плане — афиши и обратная связь |
| LLM может ошибиться в объяснении | Неточное «почему» | Генерация только из кандидатов, валидатор, длина ≤ 200, факты из кода |
| Стоимость LLM | Расходы растут с аудиторией | Gemini Flash, кэш эмбеддингов и частых запросов, разбор запроса без LLM для простых фраз |
| Задержка (LLM + внешние API) | Ожидание > 5 с | Таймауты, кэш погоды 15 мин, OSRM 3 с с фолбэком на прямые; [TBD] p50 по eval |
| Недоступность LLM / внешних API | Нет ответа | Режим деградации: ранжирование + шаблонные объяснения; прямые линии вместо OSRM |
| Время в пути — оценка по прямой × 1,3 | ±20–30 % | OSRM для маршрута; для машины — запас на такси/парковку |
| Нет офлайн-режима | В метро / без сети не работает | В плане — офлайн-кэш района |
| Доступность (`wheelchair`) размечена у малой доли мест | Мало вариантов для кресла | Показываем только подтверждённые; приглашаем разметку от сообществ |
| Казахский язык: LLM пишет хуже, чем на русском | Неестественные фразы | Проверка в eval (T12), ревью носителем, глоссарий топонимов |
| Покрытие только Астаны | Вне города — нет ответа | Честное предупреждение (кейс T17) |

## План развития
1. **0–3 мес.** События из афиш (официальные API площадок, Visit Astana), отзывы и рейтинги 2GIS, обратная связь «место закрыто» в один клик.
2. **3–6 мес.** Push «рядом интересно» (по согласию, без хранения трека), офлайн-режим района, голосовой ввод на казахском.
3. **6–12 мес.** Интеграции: Astana Hub, акимат и Smart City (городские события, перекрытия, загруженность), Visit Astana, аэропорт (виджет в зоне вылета), отели. Анонимная аналитика спроса для города.
4. **Масштаб.** Тот же конвейер для Алматы и Шымкента — сбор данных автоматический, меняется только граница города.
