# Ограничения, риски и план развития

## Ограничения и риски

| Ограничение / риск | Влияние | Как смягчаем |
|---|---|---|
| Неполнота данных (полная база, 3039 мест, 20.10.2026): часы работы есть у 53 % мест, рейтинг — у 28 %, доступность для колясок — у 6 %. В открытой выгрузке без 2GIS (2564 места) часы — у 36 %, рейтингов почти нет | Часть мест с `unknown`, мало вариантов для кресла | 2GIS API для часов и рейтингов; честная пометка уверенности; меньший вес в ранжировании |
| Описания почти все шаблонные: реальный текст из источника (Википедия, Wikidata, OSM) — у 86 из 3039 мест (3 %), остальные собраны шаблоном из полей OSM/2GIS («Кафе на ул. …, есть Wi-Fi») и помечены `description_source: template` | «Почему» опирается на теги и факты, а не на живое описание; меньше «атмосферы» | Шаблон не выдумывает фактов — только поля источника; `why` ссылается на проверяемое (расстояние, часы, теги, рейтинг); для знаковых мест описания уже из Википедии/Wikidata (86 мест), для остальных — рубрики 2GIS; LLM-пересказ только из полей источника с пометкой `llm_summary` |
| Фото под свободной лицензией есть только у 70 мест (2 %, Wikimedia Commons) | Большинство карточек — с иллюстрацией категории | Иллюстрация помечена; фото добираем из Wikidata/Commons; чужие фото (2GIS, Google) не берём |
| Устаревание: места закрываются, меняют часы | Рекомендация закрытого места | Пересбор по расписанию (cron), дата проверки у каждого места, `data_quality` учитывает свежесть |
| Временные события и ремонты не в базе | Неожиданно закрыто | Пометка «уточните перед выходом»; в плане — афиши и обратная связь |
| LLM может ошибиться в объяснении | Неточное «почему» | Генерация только из кандидатов, валидатор, длина ≤ 200, факты из кода |
| Стоимость LLM | Расходы растут с аудиторией | Gemini Flash, кэш эмбеддингов и частых запросов, разбор запроса без LLM для простых фраз |
| Задержка (LLM + внешние API) | Медиана 3,6 с, но 7 из 38 ответов > 5 с | Таймауты, кэш погоды 15 мин, OSRM 3 с с фолбэком на прямые; бюджет LLM 6 с, дальше — ответ без ИИ. Eval с Gemini: медиана 3,6 с, p95 7,1 с, 7 из 38 ответов дольше 5 с |
| Лимиты бесплатного тарифа Gemini (запросы в минуту, суточная квота; на хакатоне квоту уже исчерпали при индексации) | Часть ответов уходит в режим деградации — шаблонные объяснения | Эмбеддинги батчами и с кэшем, кэш частых запросов, разбор простых фраз без LLM; в продакшене — платный тариф или Vertex AI |
| Недоступность LLM / внешних API | Нет ответа | Режим деградации: ранжирование + шаблонные объяснения; прямые линии вместо OSRM |
| Время в пути — оценка по прямой × 1,3 | ±20–30 % | OSRM для маршрута; для машины — запас на такси/парковку |
| Нет офлайн-режима | В метро / без сети не работает | В плане — офлайн-кэш района |
| Доступность (`wheelchair`) размечена у малой доли мест | Мало вариантов для кресла | Показываем только подтверждённые; приглашаем разметку от сообществ |
| Казахский язык: LLM пишет хуже, чем на русском | Неестественные фразы | Проверка в eval (T12), ревью носителем, глоссарий топонимов |
| Покрытие только Астаны | Вне города — нет ответа | Честное предупреждение (кейс T17) |

## План развития
1. **0–3 мес.** События из афиш (официальные API площадок, Visit Astana), отзывы и рейтинги 2GIS, обратная связь «место закрыто» в один клик.
2. **3–6 мес.** Дашборд обезличенного спроса для НИЦ Smart City (районы × категории × время × погода, без координат людей), push «рядом интересно» (по согласию, без хранения трека), офлайн-режим района, голосовой ввод на казахском.
3. **6–12 мес.** Интеграции: Astana Hub, акимат и Smart City (городские события, перекрытия, загруженность), Visit Astana, аэропорт (виджет в зоне вылета), отели. Анонимная аналитика спроса для города.
4. **Масштаб.** Тот же конвейер для Алматы и Шымкента — сбор данных автоматический, меняется только граница города.
