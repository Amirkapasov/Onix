# Серуен — RAG-бэкенд (FastAPI)

API строго по [`contracts/api.md`](../contracts/api.md): `POST /api/recommend`, `GET /api/pois`, `GET /api/presets`, `GET /api/health`.

## Запуск (из корня репозитория)
```bash
python3.12 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cp .env.example .env
.venv/bin/uvicorn backend.app.main:app --reload --port 8000
```
Без ключей LLM сервис работает в **режиме деградации**: ранжирование + шаблонные «почему»/«что делать» и предупреждение в `warnings`, `llm.provider = "none"`.

Тесты (без сети и без LLM, LLM-путь проверяется фейковым провайдером):
```bash
.venv/bin/python -m pytest backend/tests -q
```

Проверка LLM-пути на всех пресетах + запросах kk/en (задержка, JSON, язык), нужен ключ в `.env`:
```bash
.venv/bin/python -m backend.scripts.check_llm
```

## Переменные окружения (`.env`)
| Переменная | По умолчанию | Что |
|---|---|---|
| `LLM_PROVIDER` | `gemini` | `gemini` / `anthropic` / `openai`. Без ключа выбранного провайдера → деградация |
| `GEMINI_MODEL` | `gemini-3.8-flash` | модель генерации и разбора запроса |
| `GEMINI_EMBED_MODEL` | `gemini-embedding-001` | эмбеддинги (поддержан и `gemini-embedding-2`) |
| `ANTHROPIC_MODEL`, `OPENAI_MODEL` | | для разработки |
| `POIS_PATH` | `data/pois.json` | если файла нет → `data/seed/pois_seed.json`; файл перечитывается при изменении |
| `OSRM_FOOT_URL` | routing.openstreetmap.de | геометрия маршрута, таймаут 3 с, иначе прямые линии |
| `LLM_TIMEOUT_S` / `LLM_PARSE_TIMEOUT_S` | 8 / 4 | таймауты (1 ретрай) |
| `SERUEN_DISABLE_LLM`, `SERUEN_DISABLE_NETWORK` | | `1` — принудительно без LLM / без сети |

## Конвейер `/api/recommend` (`app/pipeline.py`)
1. **Разбор запроса** — `parse.py`: правила на регулярках (всегда: бюджет «30–60 минут»/«2 часа», дети, тихо, кофе, розетки, ночь, вылет, −20…) + LLM в JSON-режиме (t=0) параллельно с погодой. LLM только дополняет правила, мусор отбрасывается. Явные `filters` UI важнее текста.
2. **Жёсткие фильтры (код)** — `rank.hard_filter`: haversine; пешком 4.5 км/ч × 1.3, машина 30 км/ч × 1.2 + 5 мин; радиус = дорога в одну сторону ≤ 33 % бюджета (45 % если цель — прогулка); часы работы на момент *прихода* и хватит ли времени на визит; без часов ночью скрываются закрытые по типичным часам категории (музей и т. п.); дети / доступность / только помещения / категории. Мало мест → радиус расширяется (×1.6, до 3 раз) с предупреждением. «Скоро вылет» → режим такси, запас 60 мин, учитывается дорога обратно в аэропорт.
3. **Поиск** — `search.py`: BM25 (свой стеммер + русские синонимы тегов) + эмбеддинги Gemini (кэш `data/cache/emb_*.npy`, запросы кэшируются в памяти), гибрид 50/50. Без ключа — только BM25.
4. **Ранжирование** — `rank.rank`, веса в `config.WEIGHTS`: релевантность 0.40, мягкие пожелания/интент 0.20, близость 0.15, рейтинг/популярность 0.10, data_quality 0.05, уверенность в часах 0.10, погода ±0.10 (Open-Meteo по центру города, кэш 15 мин; при сдвинутом времени демо — климатическая норма месяца; температура из запроса важнее), время суток ±0.10. Разнообразие: штраф за повтор категории. В LLM уходит top-9.
5. **Генерация** — `generate.py`: LLM видит только кандидатов (id, факты, расстояние, часы и уверенность) и возвращает JSON `{recommendations:[{poi_id, why, what_to_do, visit_min}], ideas:[…]}`.
6. **Валидатор** — `validate.py`: удаляет `poi_id` не из кандидатов (с предупреждением), пересчитывает `distance_m`/`travel_min`/`open_status` кодом, обрезает тексты (200/250), вырезает «открыто сейчас», если статус не `open`; пусто → top-3 с шаблонными текстами.
7. **Маршрут** — `route.py`: ближайший сосед от старта, урезание под бюджет, геометрия OSRM (foot/car) или `straight_line`.

Уверенность в часах (`hours.py`): `high` — 2GIS/офиц. сайт, проверено ≤ 30 дней; `medium` — OSM/ручные; `low` — нет часов или данные старше года. Нет часов → `unknown` + `low`, текст «уточните перед выходом» (для открытых территорий — «обычно доступна»).

## Демо-фишки
- `weather_override: {"temp_c", "wind_ms"}` в запросе подменяет Open-Meteo, в `context_used.weather` — «(симуляция)». Пресет «Зимний вечер» несёт его сам.
- Пресеты содержат `mode` и `icon`.
- Место, где пользователь уже стоит (метка локации/запрос + < 250 м), при прогулке не рекомендуется — уходит в `ideas` как запасной вариант.
- Шаблонные `why` (без LLM) объясняют причину выбора (совпадение с запросом, погода, время), а не расстояние.
- Погода: Open-Meteo с таймаутом 2 с, прогрев при старте, при сбое — климатическая норма и повтор не чаще раза в 2 мин.

## Приватность
Координаты огрубляются до 3 знаков и на сервере; в логах — максимум 2 знака; ничего не сохраняется. Погода запрашивается по центру города, а не по точке пользователя.
